# Cuentas Vendidas

App Android para controlar cuentas vendidas (Netflix, Spotify, etc.):

- Importa tu Excel (`.xlsx`, `.xls` o `.csv`): detecta solas las columnas y puedes cambiarlas antes de importar.
  Si vuelves a importar, actualiza las cuentas que ya estaban sin duplicarlas.
- Dos fechas por cuenta: **Vence proveedor** (donde compras/renuevas) y **Vence cliente** (lo que vendiste).
- Tarjeta usada en cada cuenta, cliente y teléfono.
- Filtros: Todas, Por vencer, Vencidas, Renovadas; búsqueda por cliente, cuenta o tarjeta.
- Aviso 1 día antes de cada fecha (indica si es la del cliente o la del proveedor), con botón para escribir al cliente por WhatsApp.
